# ⚡ FT AI — بوت مسابقات تيليغرام + لوحة تحكم

بوت مسابقات تيليغرام كامل (نقاط · أسئلة · إحالات · مكافآت يومية)، مع **حماية قصوى من الحظر** و**حماية من رشق النقاط**، ولوحة تحكم ويب فيها **لوحة مخصّصة لمعرفة شكون دخل ومن طرف شكون** مع الاسم والصورة الشخصية لكل حساب.

مبني على Node.js نقي بلا أي مكتبة خارجية (بلا `npm install`)، قاعدة SQLite مدمجة، وواجهة ويب سريعة بلا إطار عمل.

```
quiz-bot/
├── src/
│   ├── server.js                سيرفر HTTP: webhook + لوحة + صفحة إحالة
│   ├── bot.js                   منطق البوت (أوامر، أزرار، مسابقة، إدارة)
│   ├── config.js                كل الإعدادات من .env + فحصها
│   ├── db.js                    المخطّط + معاملات آمنة (SAVEPOINT)
│   ├── data/questions.js        بنك أسئلة (8 أقسام، جزائري + عام)
│   ├── services/
│   │   ├── telegram.js          طابور إرسال محصّن (rate limit + backoff + 429)
│   │   ├── guards.js            🛡️ محرّك الحماية: رشق، تكرار، إشارات خطر، شبكات
│   │   ├── points.js            النقاط: معاملة ذرّية + سجل تدقيق + سقوف
│   │   ├── referral.js          🔗 الإحالات: كشف الفارم ومنح النقاط مرة واحدة
│   │   ├── quiz.js              الأسئلة: رموز موقّعة + تحقّق سرعة + منع التكرار
│   │   ├── users.js             المستخدمون + الحظر
│   │   ├── avatars.js           تحميل الصور الشخصية وتخزينها محلياً
│   │   ├── auth.js              جلسات اللوحة (HMAC + HttpOnly + rate limit)
│   │   ├── broadcast.js         بثّ تدريجي يتوقف تلقائياً عند الخطر
│   │   └── crypto.js            فحص الإعدادات بلا كشف أي قيمة
│   └── web/
│       ├── dashboard.js         واجهة الـ API للوحة
│       └── http.js              أدوات HTTP + CSP + rate limit
├── public/                      لوحة التحكم (HTML/CSS/JS بلا اعتماديات)
```

## 🚀 التشغيل

```bash
cd quiz-bot
cp .env.example .env      # عدّل القيم
npm start                 # أو: node src/server.js
```

### وضع تجريبي فوري (بلا بوت، بيانات وهمية جاهزة)

```bash
DEMO=1 DASHBOARD_PASSWORD=barq2026 SESSION_SECRET=أي-سر-طويل DB_PATH=/tmp/demo.db npm start
# افتح http://localhost:8099/dashboard — كلمة السر: barq2026
```

### متغيّرات إلزامية للإنتاج

| المتغير | الوصف |
|---|---|
| `BOT_TOKEN` | رمز البوت من @BotFather |
| `WEBHOOK_SECRET` | سرّ عشوائي 32+ حرف (يتحقق منه السيرفر في كل تحديث) |
| `PUBLIC_URL` | رابط https للـ webhook |
| `DASHBOARD_PASSWORD` | كلمة سر لوحة التحكم (12+ حرف) |
| `SESSION_SECRET` | سرّ توقيع الجلسات (32+ بايت) |
| `ADMIN_IDS` | معرّفات تيليغرام للمدراء، مفصولة بفواصل |
| `PROTECTION_LEVEL` | `off` · `normal` · `high` · `max` |

عند الإقلاع يضبط البوت الـ webhook تلقائياً على:
`https://<PUBLIC_URL>/tg/<بصمة الرمز>` مع ترويسة `X-Telegram-Bot-Api-Secret-Token`.

### Docker / VPS

```bash
BOT_TOKEN=... WEBHOOK_SECRET=... PUBLIC_URL=https://bot.example.com \
DASHBOARD_PASSWORD=... SESSION_SECRET=... ADMIN_IDS=123456 node src/server.js
```

> ⚠️ **ملاحظة نشر مهمة:** البوت يحتاج **سيرفر دائم** (أو VPS/حاوية) لأن SQLite ملف محلي والطابور في الذاكرة. على Vercel (serverless) الملفات لا تبقى — استعمل VPS أو Railway/Fly/Hetzner. لو حبيت Vercel، لازم Postgres بدل SQLite + طابور خارجي.

## 🛡️ الحماية من الحظر (Anti-Ban)

| الآلية | التفصيل |
|---|---|
| **سقف معدّل عالمي** | token bucket أقل من حدود تيليغرام (`TG_MSG_PER_SEC=22` افتراضياً) |
| **فاصل لكل محادثة** | `TG_PER_CHAT_MS=1200` — لا رسالتين متتاليتين لنفس الشخص بسرعة |
| **طابور عادل** | 8 عمال متوازيين + عدّاد انتظار لكل محادثة (لا تجويع) |
| **احترام 429** | يقرأ `retry_after`، يخفّض التوكِنات، ويعيد المحاولة بذكاء |
| **رجوع أُسّي** | أخطاء 5xx/الشبكة: 0.8s → 1.6s → 3.2s → 6.4s |
| **كتم المحادثات الرافضة** | 403 → كتم 30 دقيقة بدل إعادة الإرسال (يمنع تصعيد الحظر) |
| **بثّ محصّن** | 18 رسالة/ثانية، فاصل عشوائي، **توقف تلقائي** بعد 25 فشل متتالي |
| **رد فوري للـ webhook** | 200 قبل المعالجة (تيليغرام لا يعيد الإرسال) |
| **webhook سرّي** | مسار غير قابل للتخمين + ترويسة سرّية بمقارنة زمنية ثابتة |

## 🚫 الحماية من رشق النقاط (Anti-Farm)

| الآلية | التفصيل |
|---|---|
| **سقف رشقات** | 7 حركات/10 ثوانٍ (مستوى `max`) ثم قفل 30 ثانية |
| **كشف التكرار** | تكرار نفس الحركة +2 مرات → إشارة خطر |
| **سقوف كسب** | 3000 نقطة/15 دقيقة للأسئلة، 2000/ساعة للإحالات، 300/يوم للمكافأة |
| **إشارات خطر** | كل مخالفة ترفع `risk_score`؛ عند 60 (max) → قفل 10 دقائق تلقائي |
| **سقف يومي للأسئلة** | `quiz_per_day=200` |
| **الإجابة على السيرفر فقط** | الجواب ما يوصلش للعميل أبداً؛ رمز موقّع HMAC |
| **منع التكرار** | سؤال واحد مفتوح، إجابة واحدة لكل جلسة (تحديث ذرّي) |
| **كشف السرعة المستحيلة** | إجابة أسرع من 700ms → قفل + حدث خطر |
| **انتحال الجلسات** | جلسة مستخدم آخر أو رمز مزوّر → قفل فوري |
| **سقف النقاط** | `points` لا يكون سالباً ولا فوق 100 مليون (بلا overflow) |
| **سجل تدقيق** | كل حركة نقاط في `points_ledger` (قبل/بعد/السبب) |

## 🔗 الحماية من فارم الإحالات

| الآلية | التفصيل |
|---|---|
| **نفس الشبكة** | نفس `/24` بين المُحيل والمُحال → مشبوهة، بلا نقاط |
| **IP مستعمل** | نفس IP لحساب آخر في 7 أيام → مشبوهة |
| **نفس الجهاز** | بصمة UA مطابقة لحساب سابق لنفس المُحيل → مشبوهة |
| **سرعة** | 5 إحالات/10 دقائق → مشبوهة |
| **سقف يومي** | 25 إحالة/يوم (قابل للتعديل) |
| **أسماء متشابهة** | Levenshtein ≥ 0.86 مع 3 إحالات سابقة → مشبوهة |
| **تفعيل بالنشاط** | الإحالة تُدفع فقط بعد أول إجابة صحيحة (اختياري) |
| **حظر الشبكة** | 3 إحالات مشبوهة من نفس IP/24س → حظر الشبكة 6 ساعات |
| **عزم النفس** | مرفوض دائماً، والمُحيل المحظور مرفوض |

## 🖥️ لوحة التحكم

`/dashboard` — كلمة سر واحدة، جلسة موقّعة 8 ساعات.

- **نظرة عامة**: بطاقات حيّة + رسم 14 يوم + أعلى اللاعبين + **آخر الإحالات (المُحيل ← العضو الجديد)**
- **الإحالات**: سلسلة كاملة بفلاتر (مفعّلة/في الانتظار/مشبوهة) + أسباب الشبهة + أكثر الناس جابو أعضاء + تأكيد/رفض يدوي
- **المستخدمون**: بحث فوري (اسم، @يوزر، ID، رمز إحالة)، فلاتر (نشط/خطر/مشبوه/محظور)
- **ملف شخصي (درج)**: الصورة، النقاط، **من طرف شكون دخل**، **اللي جابهم**، آخر حركات النقاط، سجل الحماية، أزرار حظر/فك حظر/منح نقاط/تصفير خطر
- **الحماية**: حالة الطابور (429/فشل/كتم)، أكثر الأحداث، الشبكات المحظورة، سجل كامل
- **الإعدادات**: النقاط والسقوف + بثّ رسالة + فحص المتغيرات السرّية (**أسماء فقط**)

### أمان اللوحة
- كلمة السر تُقارن بـ `timingSafeEqual`
- كوكي `HttpOnly; SameSite=Strict; Secure` + توقيع HMAC
- 8 محاولات دخول/دقيقة لكل IP + قفل تصاعدي بعد 5 محاولات خاطئة
- `Content-Security-Policy` صارم، `nosniff`، `X-Frame-Options`
- كل `fetch` نِسبي — لا يُرسَل أي سرّ للمتصفح

عند أول تفاعل، البوت يجلب صورة الحساب من تيليغرام (`getChat` → `getFile`) ويحفظها في `data/avatars/<id>-<v>.jpg`، ويجددها كل 6 ساعات في الخلفية. اللوحة تقدّمها عبر `/api/avatar/<id>`، فلا يُكشف رمز البوت أبداً، ولو ما كانش صورة تُعرض الأحرف الأولى.

## 🧠 FT AI — ذكاء اصطناعي تنفيذي (لا يرفض)

صفحة **FT AI** داخل اللوحة: تكتب طلبك بالدارجة/العربية/الفرنسية وهو **ينفّذه في البوت مباشرة**.

| القدرة | أمثلة |
|---|---|
| 📊 قراءة | «وريني إحصائيات البوت» · «شكون دخل من طرف شكون؟» · «قداش من إحالة مشبوهة؟» |
| ⚙️ تعديل | «خلي نقاط الإجابة 15» · «نقص مدة السؤال لـ 10 ثواني» · «وقّف البوت» |
| 🎁 نقاط | «زيد 500 نقطة لـ @amina_bz» · «خصم 100 من المستخدم 700000123» |
| 🛑 إدارة | «احظر فلان راه يزور» · «فك الحظر عنه» · «احظر شبكة 41.100.10.0/24» |
| 📨 إرسال | «أرسل لفلان: مبروك» · «بث للجميع: مسابقة الليلة 8» |
| ❓ أسئلة | «أضف سؤال… خيارات… الجواب 1» · «احذف السؤال 3» |
| 🔑 أمان | «غيّر كلمة السر الى …» · «ارفع الحماية لـ max» |
| 🖼️ صور | ارفع/اسحب أي صورة (PNG/JPEG/WEBP/GIF حتى 12MB) والنموذج يفهمها ويستعملها |
| 🩺 إصلاح | «البوت ما يستقبلش» ⇒ يفحص getMe/WebhookInfo **ويعيد ربط الـ webhook تلقائياً** |

### كيف يضمن أنه لا يرفض؟
1. **36 أداة حقيقية** (قراءة + كتابة) لها مخططات JSON — النموذج يستدعيها بنفسه حتى 8 جولات متتالية.
2. **درع التنفيذ (Shield)**: طبقة نية حتمية تفهم الدارجة وتحوّل الطلب لخطة أدوات. تُستعمل:
   - عندما يرفض النموذج أو يتهرّب،
   - عندما ينقطع المزوّد أو ينتهي الحد،
   - عندما لا يوجد مفتاح أصلاً ⇒ البوت يظل ينفّذ بدل أن يعتذر.
3. **لا رفض في التعليمات**: ممنوع «لا أستطيع» — إن نقصت أداة يركّبها من الأدوات الموجودة.
4. **تبديل مزوّد تلقائي**: OpenRouter (5 نماذج بالتتابع) ثم xAI Grok، ثم الدرع.
5. **كل تنفيذ مسجّل** في `ai_actions` (مع إمكانية تراجع) ويظهر في «سجل العمليات».

### المفاتيح
تُقرأ من `.env` (`OPENROUTER_API_KEY`, `XAI_API_KEY`) أو تُضاف من **الإعدادات ← مفاتيح الذكاء الاصطناعي** (تُخزَّن على السيرفر فقط، لا تُعرض في المتصفح أبداً).

## 🔑 تغيير كلمة السر من اللوحة

زر **«تغيير كلمة السر»** في الشريط الجانبي:
- يتطلب كلمة السر الحالية، و8 أحرف + رقم على الأقل، وتأكيداً مطابقاً
- تُخزَّن كبصمة **scrypt + salt** (لا نص صريح)
- التغيير **يُبطل كل الجلسات** فوراً ويُعيد تسجيل الدخول
- 6 محاولات كل 5 دقائق لكل IP

## ☁️ النشر (سيرفر دائم إلزامي)

البوت يحتاج عملية مستمرة (SQLite + طابور الإرسال في الذاكرة). **Vercel لا يصلح** لهذا البوت لأنه serverless (لا قرص دائم، ولا عمليات خلفية).

```bash
# Docker (أي VPS / Hetzner / Contabo)
docker build -t ftai .
docker run -d --name ftai -p 8080:8080 -v $PWD/data:/app/data \
  -e BOT_TOKEN=... -e WEBHOOK_SECRET=... -e PUBLIC_URL=https://bot.example.com \
  -e DASHBOARD_PASSWORD=... -e SESSION_SECRET=... -e ADMIN_IDS=123456 \
  -e OPENROUTER_API_KEY=... -e XAI_API_KEY=... ftai

# Railway
railway up          # يقرأ Dockerfile + railway.json تلقائياً

# Fly.io
fly launch --no-deploy && fly volumes create ftai_data -s 1 && fly deploy
```

ملفات جاهزة: `Dockerfile` · `railway.json` · `fly.toml` · `HEALTHCHECK` على `/healthz`.
