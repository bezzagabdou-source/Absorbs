# CHINWI STORE 👑

**متجر إلكتروني كامل على تيليجرام + لوحة تحكم ويب ضخمة + مساعد ذكاء اصطناعي — Next.js + Neon Postgres + Vercel**

> شحن فري فاير • eFootball PES • تيك توك كوينز • تيليجرام بريميوم • عشرات المنتجات الرقمية • شراء الدولار من الزبائن • دفع عبر Binance / RedotPay / PayPal / BaridiMob

## ✨ المزايا

### 🤖 بوت تيليجرام (كل شيء بالعربية)
- **اشتراك إجباري** في قنواتك (`@ft_H_N_O` و `@CHNawaa` مضافة مسبقاً) مع زر «تحققت من الاشتراك».
- **أزرار منظمة ملوّنة**: 🟢 أساسية / 🟡 تحتاج مراجعة / 🔴 إلغاء ورجوع.
- **أقسام ديناميكية** من قاعدة البيانات: فري فاير، eFootball PES، تيك توك كوينز، تيليجرام بريميوم، المنتجات الرقمية.
- **بطاقة منتج** بصورة القسم، الوصف، السعر، الشارة، وعدد المبيعات.
- **حقول مطلوبة** لكل منتج (آيدي اللاعب، Konami ID، اسم المستخدم…) يسألها البوت قبل الطلب.
- **منتجات بسعر غير محدد** → طلب تسعير يصل للمالك مع بيانات الزبون.
- **دفع بالمحافظ الأربع** + زر نسخ العنوان (copy_text) + تعليمات لكل محفظة.
- **إيصال الدفع**: يقبل صورة أو PDF، يُرفق بالطلب ويُرسل للمالك مع أزرار ✅ قبول / ❌ رفض.
- **بيع الدولار**: اختيار سعر الصرف (250/255 أو أي أسعار تحددها) → الكمية → المبلغ بالدينار → إيصال.
- **طلباتي / حسابي / الدعم** + مراسلة المالك مع `/reply` للرد على الزبون من البوت.
- **بحث ذكي**: يكتب الزبون اسم منتج فيجده فوراً.
- **لوحة إدارة داخل البوت**: إحصاءات، إيصالات معلّقة، قبول/رفض، مستخدمون، إذاعة، تبديل الاشتراك الإجباري والصيانة.
- **إيموجي متحرك** (اختياري، مع احتياط تلقائي) + رسائل منسّقة HTML.
- **حماية**: منع المحظورين، وضع الصيانة، حدّ المحاولات، تحقق سرّي للويبهوك.

### 🖥 لوحة التحكم (موقع مستقل)
- **لوحة القيادة**: مستخدمون، طلبات، مبيعات اليوم/الشهر، حجم الدولار، رسم بياني 14 يوم، الأكثر مبيعاً، آخر الطلبات والمنشئين، سجل نشاط حي.
- **الطلبات**: تصفية بالحالة/النوع، بحث بالكود أو الزبون، عرض الإيصال، قبول/رفض مع ملاحظة تُرسل للزبون، حذف، تصدير CSV.
- **المستخدمون**: صورهم من تيليجرام، بحث، فلاتر (نشط/مشترون/محظورون/إداريون)، حظر وفك حظر، ترقية إداري، رسالة مباشرة، ملف كامل بطلباته وملاحظات داخلية.
- **المنتجات**: إضافة/تعديل/حذف/نسخ، سعر أو «سعر خاص»، صور (رفع مباشر إلى قاعدة البيانات)، شارات، مخزون، حقول مطلوبة، ظهور/إخفاء، تمييز ⭐️، تعديل أسعار جماعي بنسبة %.
- **الأقسام**: إيموجي، وصف، صورة غلاف، ترتيب، إظهار/إخفاء.
- **طرق الدفع**: إضافة/تعديل/تعطيل/حذف + نسخ الأرقام.
- **قنوات الاشتراك**: إضافة قناة، اختبار أن البوت يراها، تفعيل/تعطيل.
- **الذكاء الاصطناعي**: محادثة كاملة + تنفيذ عمليات + تحليل صورة أسعار واستيراد المنتجات.
- **الإذاعة**: رسالة لكل الزبائن مع معاينة وسجل نتائج.
- **الإعدادات**: هوية المتجر، رسالة الترحيب، الصيانة، الاشتراك الإجباري، أسعار الدولار، الإيموجي المتحرك، تغيير كلمة السر، تصدير البيانات.
- **الربط والتشغيل**: حالة الويبهوك، زر تفعيل البوت، بيانات البوت، قائمة تشغيل.
- **السجلات**: كل عملية مسجّلة (طلبات، تعديلات، دخول، عمليات AI).

### 🧠 المساعد الذكي (شينوي AI)
- مزوّدون: **Groq** (سريع) → **Gemini** (رؤية) → **OpenRouter** (احتياط) — ينتقل تلقائياً عند فشل أي واحد.
- يفهم بيانات متجرك الحقيقية (منتجات، أقسام، طلبات، إحصاءات) ويجيب/ينفّذ بناءً عليها.
- يخطّط العمليات كـ JSON ثم **تنفّذها بضغطة تأكيد**: إنشاء/تعديل/حذف منتج، إنشاء قسم، تعديل إعداد، حظر/فك حظر، تغيير حالة طلب، إذاعة، تعديل محفظة.
- **تحليل صورة أسعار** (مثل صور العروض): يستخرج الأسماء والأسعار ويقترح القسم، ثم تستوردها بزر واحد.

## 🧱 التقنيات

- **Next.js 16** (App Router, Turbopack) + React 19 + TypeScript
- **Tailwind CSS 4** (تصميم داكن نيون أخضر/أحمر، RTL كامل)
- **Neon Postgres** عبر `pg` (Pool مشترك + مخطط يُبنى تلقائياً)
- **Telegram Bot API** (Webhook + `after()` لرد سريع)
- **Groq / Gemini / OpenRouter** للذكاء الاصطناعي
- بدون أي مكتبة بوت خارجية — كل شيء مكتوب يدوياً ومُختبر

```
chinwi-store/
├─ src/app/                 # الموقع العام + لوحة التحكم
│  ├─ page.tsx              # واجهة المتجر (Landing)
│  ├─ admin/(panel)/…       # 12 صفحة تحكم محمية بجلسة
│  └─ api/                  # webhook, admin gateway, media, receipt, cron, health
├─ src/lib/                 # db, store, orders, bot, telegram, ai, auth, emoji, bootstrap
├─ public/catalog/          # صور العروض المرفقة (تُستخدم في البوت والموقع)
└─ scripts/                 # اختبار E2E + بيئة محلية (تيليجرام وهمي + PGlite)
```

## 🚀 النشر على Vercel (5 خطوات)

1. **ارفع المشروع** إلى GitHub (المجلد `chinwi-store`).
2. في Vercel: **Add New → Project → Import** المستودع، ثم اضبط **Root Directory = `chinwi-store`** (Framework: Next.js).
3. أضف متغيّرات البيئة (Production + Preview):
   | المتغيّر | القيمة |
   | --- | --- |
   | `DATABASE_URL` | رابط Neon (مع `?sslmode=require`) |
   | `TELEGRAM_BOT_TOKEN` | توكن البوت |
   | `ADMIN_PASSWORD` | كلمة سر لوحة التحكم |
   | `ADMIN_SECRET` | نص عشوائي طويل |
   | `TELEGRAM_WEBHOOK_SECRET` | نص عشوائي |
   | `OWNER_USERNAME` | `F_Q_Q_T` |
   | `GROQ_API_KEY` / `GEMINI_API_KEY` / `OPENROUTER_API_KEY` | مفاتيح الذكاء الاصطناعي |
4. **Deploy**. عند أول طلب: يُبنى المخطط، تُزرع 74 منتجاً + 4 محافظ + قناتان، ويُسجَّل الويبهوك **تلقائياً**.
5. **افتح رابط الموقع مرة واحدة** (أو اضغط «🔗 تفعيل البوت» في لوحة التحكم) → البوت يعمل فوراً. ثم افتح البوت من حساب المالك واضغط `/start` ليُربط حسابك بإشعارات الطلبات.

> ⚠️ يجب إضافة البوت **مشرفاً** في قنوات الاشتراك الإجباري، وإلا سيتجاوز التحقق (بشكل آمن) حتى لا تخسر زبائنك.

### التفعيل التلقائي بعد النشر
`.github/workflows/activate-bot.yml` يستدعي `/api/cron/heartbeat` بعد كل Push ليتأكد من ربط الويبهوك — يمكنك تشغيله يدوياً من تبويب Actions أيضاً.

## 🧪 الاختبار

```bash
cd chinwi-store
cd scripts/dev && npm install && cd ../..   # أدوات قاعدة البيانات المحلية (مرة واحدة)

npm run dev:all      # يشغّل DB محلية + تيليجرام وهمي + الموقع على 3100
npm run test:e2e     # 39 اختباراً من البداية للنهاية
```

يغطّي الاختبار: بوابة الاشتراك، تصفّح الأقسام والمنتجات، الشراء بالحقول، المحافظ ونسخ العناوين، الإيصال وإشعار المالك، القبول، بيع الدولار، الدعم و`/reply`، حظر المستخدمين، صيانة، كل مسارات لوحة التحكم (CRUD، تصدير، إعدادات، ويبهوك، إيموجي)، الإذاعة، والحماية بالجلسة.

## 🔐 الأمان

- جلسة إدارة موقّعة HMAC في كوكي `httpOnly`، وكلمة السر مشفّرة بـ **scrypt**.
- حدّ المحاولات على تسجيل الدخول + تسجيل كل محاولة فاشلة.
- الويبهوك يتحقق من هيدر `X-Telegram-Bot-Api-Secret-Token`.
- إيصالات الدفع وصور المستخدمين تُخدَّم فقط بجلسة إدارة.
- أي عملية من الذكاء الاصطناعي تمرّ بقائمة عمليات مسموحة وتُسجَّل في السجلات.

## 🩺 استكشاف الأخطاء

| المشكلة | الحل |
| --- | --- |
| البوت لا يستجيب | افتح صفحة **الربط والتشغيل** واضغط «ربط / إعادة ربط البوت» |
| «قاعدة البيانات غير متصلة» | تحقق من `DATABASE_URL` (يجب أن يحتوي `sslmode=require`) وأعد النشر |
| لا تصل إشعارات الطلبات | افتح البوت من حساب المالك واضغط `/start` (يتعرّف عليه من `OWNER_USERNAME`) |
| الاشتراك الإجباري لا يعمل | أضف البوت مشرفاً في القنوات ثم «اختبار» في صفحة القنوات |
| الذكاء الاصطناعي لا يرد | أضف مفتاح Groq أو Gemini في Vercel وأعد النشر |
| نسيت كلمة سر اللوحة | استخدم `ADMIN_PASSWORD` من متغيّرات البيئة (يعمل كاحتياط) |
