# ⚡ Absorbs Bot — LEGEND EDITION

بوت تيليجرام عربي أسطوري: **حماية المجموعات + إدارة كاملة + أغاني يوتيوب + ألعاب + قرآن + أدوات ذكية + اقتصاد + ردود خارقة** — **أكثر من 585 ميزة**، يعمل على Vercel (Serverless) بلا أي خادم.

> اكتب `الميزات` داخل البوت لرؤية العدد الحقيقي لكل فئة، و`الاوامر` للقائمة التفاعلية.

## 🚀 التشغيل على Vercel

1. ارفع هذا المجلد (`telegram-bot/`) كجذر المشروع على Vercel (Framework: Other).
2. أضف متغير البيئة `BOT_TOKEN` (توكن البوت من @BotFather).
3. انشر (Deploy).
4. افتح الرابط لإعداد كل شيء تلقائياً:
   ```
   https://<project>.vercel.app/setup?key=<SETUP_KEY>
   ```
   حيث `SETUP_KEY = sha256(BOT_TOKEN)[:24]`. هذا الرابط يضبط الويب هوك + التخزين الدائم + أوامر البوت تلقائياً.
5. تحقق من الحالة: `https://<project>.vercel.app/health`

> ملكية البوت تُفعّل بمفتاح المطور: أرسل في خاص البوت `مفتاح المطور <SETUP_KEY>` (أو اضبط `OWNER_ID`). لا يُمنح تلقائياً لأول `/start`.

## 🛡 تفعيل الحماية في مجموعة
1. أضف البوت للمجموعة وارفعه **مشرفاً** بكل الصلاحيات (حذف، حظر، تقييد، تثبيت، دعوة).
2. اكتب `تفعيل` في المجموعة.
3. (مهم) عطّل Privacy Mode من @BotFather عبر `/setprivacy` → Disable ليفحص البوت كل الرسائل.

- **الإسلاميات:** قرآن صوتي (114 سورة)، آية عشوائية، أذكار، أدعية، سبحة.

- **المطور:** إذاعة، حظر عام، رفع مطورين، الحالة.

## 💬 نظام الردود الخارق (اضف رد / احذف رد)
- `اضف رد كلمة | الرد` — رد نصي، و`اضف رد كلمة | رد1 || رد2` — رد عشوائي متعدد.
- ردّ على صورة/ملصق/صوت/فيديو ثم `اضف رد كلمة` — رد بالوسائط نفسها.
- `احذف رد` · `عدل رد` · `تفعيل رد` · `تعطيل رد` · `بحث رد` · `الردود` (مع إحصائيات الاستخدام) · `مسح الردود`.
- متغيرات ذكية: `{name}` `{username}` `{id}` `{group}` `{date}` `{time}` `{random:أ|ب|ج}`.

## ⚡ تحسينات "مايكي" (سهولة + حماية فورية + ذكاء)
- **أوامر ببادئة / أو !:** `/حظر` `!كتم` `/طرد` `!تحذير` `/قوانين` — أوامر مختصرة سهلة.
- **حماية افتراضية فورية:** حذف الروابط تلقائياً + فلتر السب (31 كلمة عربية قابلة للتعديل) يعملان بمجرد التفعيل.
- **إنذار تدريجي:** تحذير أول ← ثانٍ ← ثم كتم/طرد تلقائي (حد التحذيرات قابل للضبط).
- **الرد الذكي 🤖:** منشن البوت `@` أو الرد على رسالته → يجيب بذكاء وودّ (تحية، كيفك، من انت، شكرا، نكتة، الوقت…).
- **معالج الردود 🧙:** اكتب `اضف رد` وحدها → يفتح معالج خطوة بخطوة (كلمة ← رد نصي/صورة مع تعليق/وسائط ← تم)، مع ردود عشوائية وأزرار.
