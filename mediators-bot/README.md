# 🛡️ بوت الوسطاء المضمونين — XR / BM / FT

بوت تيلغرام + لوحة تحكم موقعية زجاجية عصرية.

## التشغيل
```bash
pip install -r requirements.txt
python bot.py        # تشغيل البوت
python dashboard.py  # لوحة التحكم على http://localhost:5000
```
التوكن موجود افتراضياً داخل الملفات، ويمكن تغييره عبر متغير البيئة `BOT_TOKEN`.

## الأقسام
- 🛡️ وسطاء XR (مع الصورة + المالك/الشكاوى/الكروب/المتجر)
- ⚔️ وسطاء BM (مع الصورة)
- 🎩 وسطاء FT (مع الصورة)
- 👑 وسطاء ومالكين
- 🎁 وسطاء مجانيين مؤقتاً
- 🚨 منتحلين الوسطاء (فارغة — لم يتوفر أي محتال بعد ✅)
- 📊 إحصائيات: عدد المستخدمين الذين دخلوا البوت

## لوحة التحكم
- إحصائيات مباشرة (مستخدمين / وسطاء / منتحلين)
- إضافة وحذف أي عنصر في أي قسم بضغطة زر
- رسالة جماعية لكل مستخدمي البوت
- كل التعديلات تُحفظ في `data.json` وينعكس فوراً على البوت

## النشر السريع
- البوت + اللوحة: ارفع على Railway أو Render أو أي سيرفر (الأمر: `python bot.py` و `python dashboard.py`)
- أو شغّل اللوحة فقط على Vercel عبر صفحة Next.js في `src/app/mediators`
