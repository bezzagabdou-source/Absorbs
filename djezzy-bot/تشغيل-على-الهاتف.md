## ⚡ الطريقة السريعة (أمر واحد)

1. ثبّت **Termux** من F-Droid: <https://f-droid.org/packages/com.termux/>
2. افتح Termux والصق هذا السطر الواحد:

```bash
curl -sL https://raw.githubusercontent.com/bezzagabdou-source/Absorbs/main/djezzy-bot/install-termux.sh | bash
```

سيقوم كل شيء تلقائياً: تثبيت Node.js، تحميل المشروع، إنشاء `.env`،
إزالة الـ Webhook، ثم تشغيل البوت. انتظر حتى تظهر لك رسالة **✅ البوت يشتغل الآن**.

3. افتح تيليجرام → **@Djezzynetbot** → `/start` → **📱 إضافة رقم** → `+2137XXXXXXXX`
   → سيصلك رمز SMS → أدخله → بعدها **🎁 هدية 2 جيجا** تتفعّل فعلياً.

> لإعادة التشغيل لاحقاً: `cd ~/Absorbs/djezzy-bot && npm run poll`
> لوقف البوت: `Ctrl+C`

## 4) شغّل البوت

```bash
termux-wake-lock        # يمنع النظام من إيقاف Termux
npm run poll
```

سترى:

```
📄 قُرئ N مفتاحاً من .env…
[INFO] [bot] تم تهيئة البوت (وضع جيزي: live)
[INFO] [dev] البوت @Djezzynetbot يعمل بالـ polling (وضع جيزي: مباشر)
```

الآن افتح تيليجرام → البوت → **📱 إضافة رقم جديد** → أرسل `+2137XXXXXXXX`
→ سيصلك **رمز SMS حقيقي** → أدخله → ستُربط الجلسة وتُحفظ في `.data/store.json`
(لا تحتاج إدخال الرمز مرة أخرى بعد إعادة التشغيل).

> ⚠️ مهم: **أوقف الـ Webhook** لأنه يتعارض مع الـ polling. نفّذ الأمر مرة واحدة:
> ```bash
> npm run delete-webhook
> ```

## 5) للتشغيل لاحقاً

```bash
cd ~/Absorbs/djezzy-bot && npm run poll
```

- `npm run poll:dry` = تجربة الواجهة كاملة بلا أي طلب حقيقي.
- `npm run doctor` = فحص الإعدادات.
- لتحديث الكود: `git pull && npm install`.

## ملاحظات

| الحالة | النتيجة |
|---|---|
| هاتف على شبكة جيزي (بيانات الهاتف) | ✅ الأفضل — يعمل بلا مشاكل |
| هاتف على Wi‑Fi جزائري (Djaweb/Idoom…) | ✅ يعمل عادةً |
| VPN أجنبي على الهاتف | ❌ سيفشل (نفس مشكلة Vercel) |

- الإشعار «الجلسات ستُفقد» يخصّ Vercel فقط؛ محلياً الجلسات محفوظة على القرص.
- شغّل خيار «منع إيقاف التطبيق» (Battery → Unrestricted) ليبقى البوت يعمل في الخلفية.
- إن أردت تشغيلاً دائماً بلا هاتف: أي VPS **جزائري** (Djaweb / ICOSNET…) بنفس الخطوات و`npm start`.
