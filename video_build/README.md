# GTA VI — Arabic viral short (35–40s, 1080x1920 @60fps)

Fully programmatic render: no NLE, no stock footage, no text overlay plugin.
Every layer is generated by the scripts in this folder.

| Stage | File | Output |
|---|---|---|
| Voice track | `proc_vo.py` | cleaned, de-essed, time-fitted فصحى VO (`vo_proc/`) |
| Motion plates | `motion.py` | 10 background plates, Ken-Burns / whip-pan, split-tone grade, grain |
| Music + SFX | `audio_builder.py` | procedural 140 BPM dark-trap bed, risers/impacts/whooshes, VO ducking |
| Compositor | `render_cards.py` | kinetic Arabic captions, HUD, emojis, glitch/whip/flash transitions, snap-zoom cuts |
| Master | `assemble.py` | concat + two-pass EBU R128 to **-14 LUFS / -1 dBTP** |

## Technical notes

* **Arabic typography** — Cairo/Noto-Kufi are shaped with `arabic_reshaper` + `python-bidi`;
  FFmpeg's HarfBuzz `drawtext` was used to validate the shaping. Calligraphic fonts that
  lack Arabic *presentation forms* in the cmap render tofu boxes under PIL, so
  Noto Kufi Arabic 900 (100 % coverage of the required forms) is used for all captions.
* **Timing** — the VO is the clock. `audio_builder.py` walks the scene list, writes
  `timeline.json`, and the compositor uses that file for both cut points and
  word-level caption highlighting, so audio and picture cannot drift.
* **Pacing** — 30 frames-level shots across 39.3 s; the longest single shot is 2.06 s.
* **Sync check** — cross-correlation of every VO segment against the master mix
  measures ≤ 20 ms offset on all ten scenes.
