# متجر توابل الأصيل — نسخة بلا قاعدة بيانات

أمر التشغيل `npm ci && npm run build && npm start` من `spice-store`. السر الوحيد المطلوب للإدارة هو `ADMIN_PASSWORD` على الخادم (كلمة مرور قوية وفريدة). لا يوجد اتصال بـ Supabase ولا تخزين لبيانات الدخول داخل الكتالوج. تغيير السر وإعادة النشر يبطل الجلسات السابقة.

الواجهة تعرض `src/data/catalog.json` مباشرة، ثم تطلب آخر نسخة سليمة من نفس الملف على فرع المتجر في GitHub. عند انقطاع GitHub تبقى النسخة المرفقة بالنشر متاحة. الطلبات عبر واتساب، والسلة محلية للمتصفح. لا تجمع النسخة عدداً مشتركاً للزيارات.

افتح `/#admin`. تعديلات الإدارة مسودة محفوظة في نفس المتصفح؛ لتنشرها لكل الأجهزة نزّل `catalog.json` من اللوحة ثم ارفعه بنفس الاسم إلى `spice-store/src/data` عبر زر GitHub واحفظ commit في فرع `arena/09b8ccc0-absorbs`. لا يلزم إعطاء التطبيق توكن GitHub. قبل تعديل الكتالوج من جهاز آخر ابدأ من النسخة المنشورة حتى لا تستبدل تغييرات أحدث. ملفات Supabase القديمة خارج التطبيق لم تُحذف ولم تُستورد.
