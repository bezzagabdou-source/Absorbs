# توابل الأصيل

تطبيق المتجر المستخرج من `spices-e-commerce-store-development.zip`. مجلد المشروع في Vercel هو `spice-store` وإطار العمل Next.js.

اضبط `DATABASE_URL` (أو `POSTGRES_URL`) لاتصال PostgreSQL دائم ومخصص للمتجر، و`ADMIN_PASSWORD` لكلمة مرور الإدارة الأولية. عند أول طلب ينشئ التطبيق الجداول الناقصة ويملأ الكتالوج داخل معاملة واحدة؛ لا يستبدل بيانات المتجر الموجودة. تغيير كلمة المرور بعد التهيئة يكون من لوحة الإدارة. الصور مرفقة في `public/images`.

شغّل `npm ci` ثم `npm run build` و`npm start`. لا يتطلب البناء الاتصال بقاعدة البيانات. افحص `/api/health` للتحقق من إمكانية قراءة المتجر الفعلي.
