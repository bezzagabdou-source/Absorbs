# 🎁 متجر النقاط والجوائز + التحكّم من لوحة FT AI

## 1) في البوت (`@mosaba9atFTbot`)

أوامر جديدة:

| الأمر | الوظيفة |
|---|---|
| `/shop` (أو `/rewards`, `/store`) | متجر الجوائز — يعرض رصيدك وكل جائزة بثمنها |
| `/daily` (أو `/gift`) | هدية اليوم (1–3 نقاط، مرة كل يوم) |
| `/join` | رابط دخول المجموعة الخاص بك (رابط دعوة شخصي) |

أزرار جديدة في `/start`:
- `🎁 متجر الجوائز` → `shop`
- `🚪 دخول المجموعة` → `join`
- داخل المتجر: `buy:<id>` → شاشة الجائزة → `confirm:<id>` → تسجيل الطلب

### كيفاش يكسب النقاط
- كل عضو جديد يدخل المجموعة **من رابطك** = `perJoin` نقاط (افتراضيًا **2**).
- هدية يومية 1–3 نقاط.
- المالك يقدر يزيد/ينقص يدويًا من اللوحة.

### كيفاش ياخذ الجائزة
1. العضو يضغط `confirm` → تُخصم النقاط فورًا ويُسجّل طلب `pending`.
2. المالك يستقبل رسالة فيها زرّين: **✅ تسليم** / **↩️ رفض وإرجاع النقاط**.
3. الرفض يرجّع النقاط تلقائيًا، والقبول يبعث رسالة تهنئة للعضو.

## 3) في لوحة FT AI (`https://ft-contests-bot.vercel.app`)

تبويب جديد **🤖 البوت** يتحكّم في البوت المربوط عن بعد:

- حالة البوت (مستخدمون، مسابقات، تخزين، مزوّد AI).
- النقاط والجوائز والمجموعة.
- طلبات الجوائز (تسليم/رفض).
- أرصدة المستخدمين وتعديلها.
- المسابقات (إنشاء/تشغيل/إيقاف/حذف).
- رسائل: لعضو واحد أو بثّ، + كتابة بالـ AI، + إيموجي وستيكرات.
- **⚡ FT AI يتصرف في البوت**: تكتب طلبك بالدارجة → يترجمه لعمليات وينفّذها فعليًا.

### المعمار
```
المتصفح → ft-contests-bot.vercel.app/api/bot   (وسيط، جلسة اللوحة)
        → ft-bot-bice.vercel.app/api/panel/rewards  (x-panel-key)
        → نفس منطق البوت (نقاط/جوائز/مسابقات/تيليغرام)
```
- المفتاح المشترك: `PANEL_PUBLIC_KEY` (في مشروع ft-bot) و`BOT_PANEL_KEY` (في ft-contests-bot).
- عنوان البوت: `BOT_BASE_URL=https://ft-bot-bice.vercel.app`.
- **الويب هوك ما تمسّش**: `PANEL_OWNS_WEBHOOK` باقي على حالو، والبوت هو اللي يستقبل تحديثات تيليغرام.

## 4) اختبار

```bash
cd ft-contest-bot
npm install
TELEGRAM_MOCK=1 ADMIN_PASSWORD=test1234 TELEGRAM_WEBHOOK_SECRET=smoke-secret npm run build
TELEGRAM_MOCK=1 ADMIN_PASSWORD=test1234 TELEGRAM_WEBHOOK_SECRET=smoke-secret npx next start -p 3210
BASE=http://127.0.0.1:3210 ADMIN_PASSWORD=test1234 TELEGRAM_WEBHOOK_SECRET=smoke-secret node scripts/smoke.mjs
```
القسم `15) متجر الجوائز` كيغطّي: `/shop`، الجوائز، الشراء، إشعار المالك، الموافقة، `/join`، وصفحة اللوحة.

فحص إنتاج سريع:
```
https://ft-bot-bice.vercel.app/api/panel/rewards?key=<PANEL_PUBLIC_KEY>&canary=1
```
يرجّع هوية البوت + حالة الويب هوك (getMe + getWebhookInfo).
