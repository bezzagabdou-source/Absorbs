# 🏆 بوت مسابقات FT + لوحة تحكم كاملة

بوت تيليغرام لمسابقات «الجهات»: كل مسابقة لها عدد جهات مطلوب (مثلاً **200 جهة**)، وأول من يكمّل العدد يضغط
**«ربح الحساب»** فيستلم **إيميل + كلمة سر** الحساب فوراً من مخزون تحدّده أنت من لوحة التحكم.

مبني بـ **Next.js 16** (App Router) ويعمل بالكامل على **Vercel**: البوت عبر Webhook في نفس المشروع،
واللوحة على `/admin`، والموقع العام على `/`.

---

## ✨ المزايا

### البوت (تيليغرام)

| الميزة | التفصيل |
| --- | --- |
| 🎯 عرض المسابقات | قائمة المسابقات المفتوحة مع تقدّمك في كل واحدة |
| 🔗 رابط إحالة لكل مستخدم | `t.me/BOT?start=r_<contest>_<user>` — كل شخص جديد = **جهة واحدة** |
| 📊 «جهاتي» | رصيدك + شريط تقدّم + الرابط + المتبقي للهدف |
| 🥇 المتصدّرون | ترتيب أفضل 10 مشاركين في كل مسابقة |
| 🎁 «ربح الحساب» | يتحقق من وصولك للهدف ثم يسلّمك الحساب من المخزون (سحب ذرّي — مستحيل حساب واحد لفائزين) |
| 🔁 إعادة الاستلام | لو الفائز ضيّع الرسالة، يضغط الزر ثاني وتُرسل له نفس بياناته |
| 🔒 اشتراك إجباري (اختياري) | البوت يتحقق من عضوية القناة عبر `getChatMember` قبل الاستلام |
| ⚡️ تسليم تلقائي (اختياري) | يسلّم الجائزة لحظة إكمال الهدف بدون ما يضغط الفائز |
| 🔔 إشعارات | إشعار لكل جهة جديدة، إشعار للإدارة بكل تسليم، وتنبيه لو نفد المخزون |
| 🛡 عدّاد ضد التكرار | نفس الشخص ما يُحسب مرتين، ولا يُحسب صاحب الرابط لنفسه |

### لوحة التحكم (`/admin`)

- 🔐 دخول بكلمة مرور (scrypt + جلسة موقّعة HMAC، أول دخول ينشئ كلمة المرور بنفسه).
- 📊 لوحة معلومات: المستخدمون، المسابقات، المخزون، الجوائز المسلَّمة.
- 🏆 إدارة المسابقات: إنشاء/تعديل/تفعيل/إيقاف/حذف، عدد الجهات، عدد الفائزين، الجائزة، الوصف.
- 📦 مخزون الحسابات لكل مسابقة: لصق دفعة كاملة سطر بسطر `email:password` (كلمات السر **مخفية دائماً** ولا تُعرض في الصفحة).
- 🥇 متصدّرو كل مسابقة + سجل كامل للجوائز المسلَّمة (الإيميل/كلمة السر/الوقت) لحل أي نزاع.
- 👥 المستخدمون + بحث بالاسم/اليوزر/الآي دي.
- 📣 بث رسائل لكل مستخدمي البوت (على دفعات لتجنّب حدود تيليغرام).
- ⚙️ تحكم كامل بالبوت من المتصفح: التوكن، القناة، الدعم، شات السجل، آي دي الأدمنز، نصوص الرسائل، واشتراك إجباري/تسليم تلقائي.
- 🔗 أزرار: **فحص التوكن** / **ربط الويب هوك بالموقع** / **ضبط أوامر البوت** / **فصل الويب هوك** — بدون أي أوامر سطر أوامر.
- 💾 يعمل مع **Upstash Redis / Vercel KV** أو **Postgres** (Neon/Supabase/Vercel Postgres)، وذاكرة محلية للتطوير.

## 🚀 النشر على Vercel (5 دقائق)

### 1) ارفع المشروع

المشروع داخل مجلد `ft-contest-bot` في هذا الريبو.

### 2) أنشئ المشروع في Vercel

1. **Add New → Project → Import** ريبو `bezzagabdou-source/Absorbs`.
2. في **Root Directory** اكتب: `ft-contest-bot` (مهم جداً).
3. Framework: **Next.js** (يُكتشف تلقائياً) — Build: `next build`.
4. قبل Deploy أضف متغيرات البيئة:

| المتغير | القيمة | إلزامي |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | توكن البوت من @BotFather | ✅ |
| `TELEGRAM_WEBHOOK_SECRET` | أي نص عشوائي طويل (حماية الويب هوك) | ✅ يُفضّل |
| `ADMIN_SECRET` | نص عشوائي 32 حرف (توقيع جلسة الأدمن) | ✅ يُفضّل |
| `ADMIN_PASSWORD` | كلمة مرور اللوحة (اختياري — أو أنشئها من صفحة الدخول) | اختياري |
| `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN` | من Storage → Upstash | ✅ |
| أو `DATABASE_URL` | رابط Postgres (Neon/Supabase) | ✅ بديل |

5. **Deploy**.

### 3) أضف قاعدة بيانات (ضروري لحفظ البيانات)

Vercel → مشروعك → **Storage** → أنشئ **Upstash Redis** (مجاني) أو **Neon Postgres** → **Connect**
→ المتغيرات تُضاف للمشروع تلقائياً → **Redeploy** مرة واحدة.

> بدون قاعدة بيانات، التخزين يكون في الذاكرة فقط: كل Deployment/إعادة تشغيل تضيّع المسابقات والحسابات.
> اللوحة تعرض تنبيهاً واضحاً في هذه الحالة.

### 4) اربط البوت بالموقع

1. افتح `https://<مشروعك>.vercel.app/admin` → أنشئ كلمة مرور اللوحة.
2. **الإعدادات** → تأكد أن التوكن محفوظ → اضغط **🔍 فحص التوكن** (يظهر يوزر البوت).
3. اضغط **🔗 ربط الويب هوك بالموقع** — يسجّل `https://<دومينك>/api/telegram/webhook` تلقائياً مع السر.
4. اضغط **⌨️ ضبط أوامر البوت** (اختياري لكن مفيد).

بعدها البوت شغّال 24/7 على Vercel — بدون سيرفر ولا VPS.

### 5) جهّز أول مسابقة

1. **المسابقات → إنشاء مسابقة**: العنوان، عدد الجهات (200)، الجائزة، عدد الفائزين (1)، الحالة **مفتوحة**.
2. ادخل المسابقة → **مخزون الحسابات** → الصق:

   ```
   user1@ft.com:Passw0rd1
   user2@ft.com:Passw0rd2
   ```

3. ابعت الرابط للجمهور: `https://t.me/<bot>?start=c_<id>` أو زر **فتح في البوت**.
4. أول ما حد يوصل 200 جهة ويضغط «ربح الحساب» → يستلم أول حساب في المخزون، وتوصلك إشعارات، والمسابقة تُغلق تلقائياً لو عدد الفائزين 1.

## 💻 التشغيل المحلي

```bash
cd ft-contest-bot
npm install
cp .env.example .env.local   # ضع التوكن (أو اتركه وضعه من اللوحة)
npm run dev                  # http://localhost:3000  و /admin
```

بدون توكن حقيقي؟ شغّل وضع المحاكاة (لا يتصل بتيليغرام إطلاقاً، ويطبع كل رسالة في سجل وهمي):

```bash
TELEGRAM_MOCK=1 TELEGRAM_WEBHOOK_SECRET=smoke-secret ADMIN_SECRET=dev-secret-1234567890 npm run dev
```

ثم في تيرمنال آخر:

```bash
ADMIN_PASSWORD=test1234 node scripts/smoke.mjs
```

السكربت يعمل **32 فحصاً** لدورة كاملة: دخول اللوحة → إنشاء مسابقة → إضافة حسابات → ربط البوت →
3 إحالات → بلوغ الهدف → استلام الجائزة → منع التسليم المزدوج → البث → الموقع العام.

## 🔐 ملاحظات أمان

- كلمة مرور اللوحة تُخزَّن مشفّرة بـ **scrypt + salt**؛ لا يمكن استرجاعها، فقط تغييرها من الإعدادات.
- الجلسة كوكي `HttpOnly` + `SameSite=Lax` + موقّعة **HMAC-SHA256** وتنتهي بعد 7 أيام.
- الويب هوك محمي بـ `secret_token` (تيليغرام يرسله في هيدر)، وأي طلب بدونه = 401.
- مخزون الحسابات **لا يُعرض أبداً** في اللوحة (إيميل مقنّع + نجوم)، ويُسحب من المخزون عملية واحدة ذرّية.
- سجل الجوائز يعرض البيانات للإدارة فقط (صفحة محمية)، لحل نزاعات «ضاع الحساب».
- لا تشارك التوكن في الأماكن العامة — غيّره فوراً من @BotFather لو تسرّب.
