# ✨ الإيموجيات المتحركة (Custom Emoji) — دليل سريع

البوت كيبدّل **كل إيموجي عادي** في الرسائل والأزرار بإيموجي متحرك `<tg-emoji emoji-id="…">` تلقائياً،
وبلا ما نلمسو أي رسالة يدوياً (التطبيق داخل `sendMessage` / `editMessage` / كابشنات الصور).

## 1) تشغيل السكربت (Termux)

```bash
pkg update -y && pkg install -y nodejs
cd ft-contest-bot
export TELEGRAM_BOT_TOKEN="123456:ABC..."     # توكن البوت من @BotFather

node scripts/emoji.mjs sync                   # يجيب الحزم العامة → src/lib/_emoji_ids.json
node scripts/emoji.mjs sync --set "Pack1,Pack2"   # حزم على ذوقك
node scripts/emoji.mjs add "PackName"         # زيد حزمة وحدة
node scripts/emoji.mjs list                   # شوف الخريطة
node scripts/emoji.mjs test "أهلاً 🔥⭐🎁"      # جرّب fx()
```

- أسماء الحزم في `emoji-packs.txt` (سطر لكل حزمة) أو من `--set`.
- السكربت يستعمل `getStickerSet` ويقرا `custom_emoji_id` من كل ملصق.

> ⚠️ ملاحظة مهمة: تيليجرام **ما كيرجعش حزم الإيموجي المخصصة العامة** عن طريق البحث
> (`getStickerSet` كيخدم غير مع اسم الحزمة بالضبط)، ودائماً كيرفض الأيقونات داخل أزرار الـ **Keyboard العادي**.
> لهذا الكود: كيخلي الإيموجي في نص الزر + `icon_custom_emoji_id` (بلا خسارة عند غير البريميوم)، وكيطبّق الاحتياط.

## 2) في الكود (TypeScript)

```ts
import { fx } from "@/lib/emoji";

await sendMessage(chatId, "أهلاً 🔥 عندك 🎁");   // fx تتطبّق وحدها
```

## 3) أوامر المالك

- `/emojis` — يعرض الإيموجيات المحمّلة وعدد النسخ.
- `/addemoji PackName` — يجيب الحزمة، يخزّنها في قاعدة البيانات ويحدّث الخريطة **بلا نشر جديد**
  (المرة الجاية اللي يخدم فيها البوت كيتدمجو تلقائياً).

## 4) متغيرات البيئة

| المتغير | الوظيفة |
|---|---|
| `EMOJI_OFF=1` | يطفّي الإيموجيات المخصصة كاملة |
| `EMOJI_STRICT=1` | يمنع العشوائية (ياخذ أول ID دائماً) |

## 5) الاحتياط (مستحيل يكسر البوت)

1. إلا رفض تيليجرام الرسالة → إعادة إرسال **نفس الرسالة بالإيموجي العادي**.
2. إلا رفض أيقونة زر → إعادة إرسال بـ**أزرار عادية**.
3. 3 رفضات متتالية → الإيموجيات تتطفّى 10 دقائق تلقائياً (بلا بطء ولا أخطاء).
