# Nexus AI v8.9 — Image Studio, Tools menu, clear model levels

## New
- **Image Studio** (`+` menu → إنشاء صور): `/api/ai/image` + `src/lib/image-gen.ts`. Photoreal prompt builder (camera, lens, light, anti-artifact rules), 7 styles, 5 aspect ratios.
  Engines: Gemini image models (fastest first for Nexus 5/6, best first for MAX) → Hugging Face FLUX.1-schnell → Pollinations FLUX. Big PNGs are re-encoded to JPEG with sharp.
  Variants per level: Nexus 5 = 1, Nexus 6 = 1 (richer detail), Nexus 8 = 2, MAX = 3 (ultra model first). Pro only.
- **Tools menu** (`+` button in the composer): images, video, music, Canvas, Deep Research, guided learning, extra upload options, personalised AI (memory).
  Video and music are real, playable HTML/WebAudio programs generated by the model (not camera video / recorded audio). Modes live in `src/lib/chat-modes.ts` and are applied server-side.
- **Model levels made explicit**: `TierCompare` card under the model switch and on the upgrade page. Every line matches the code (20k / 32k / team / 64k tokens, image variants).

## MAX
- Target raised to more than 60,000 tokens per answer (hard ceiling 64,000 per request, then automatic continuation for up to one hour).

## No more half answers when you leave the app
- If the connection drops while the app is in the background, the answer stays "pending" and the full text is fetched from the server's saved copy instead of being shown cut. A timeout now keeps whatever was already written.

## Voice call
- New "understanding" block in the call prompt (repairs speech-recognition errors, uses earlier turns, short confirmations only when it matters); listening restarts faster (120 ms) and the next turn starts 180 ms after the voice ends.

## Deploy notes
- No new dependencies. Optional env: `GEMINI_IMAGE_MODEL`. Run `npm run typecheck` before deploying.
