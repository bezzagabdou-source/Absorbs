# Nova Mira / نوفا ميرا

**Original open-world action-crime game for Android — native Godot 4 APK, no WebView.**

Nova Mira is a fictional coastal city of six districts. You arrive with nothing,
take jobs, steal and tune cars, fight rival crews, outrun a five-star police
response and buy your way up the underworld. All art, story, names, radio music
and audio are original and generated by this repository's scripts.

## Download / install

- **Direct APK download:** https://github.com/bezzagabdou-source/Absorbs/releases/download/v0.1.0/NovaMira-v0.1.0.apk (24.8 MiB, signed).
- Android 8.0+ (API 26), ARM64 device, Vulkan or GLES3, 3 GB RAM recommended.
- On Android: enable *Install unknown apps* for your browser/file manager, open
  the APK and accept the install prompt. No OBB or second data file is required.
- The v0.1 CI keystore is freshly generated per build; if Android warns that the
  app is from an unknown developer, that is expected. Uninstall an older build
  before installing a newer one if the signing key changed.

## Features in v0.1

- 2 km × 2 km seamless city, six visual districts, chunk streaming, 441-node road graph.
- Third-person on-foot controller with camera spring arm and virtual joystick.
- 10 drivable vehicles with wheel colliders, brake/handbrake, fuel, damage, smoke and explosions.
- 8 weapons: fists, bat, pistol, SMG, rifle, shotgun, sniper, grenade; recoil, spread, decals, aim assist.
- 1–5 star wanted system: officers, cruisers, roadblock escalation, helicopter at 5 stars, cooldown and arrest.
- 5 story missions + 4 repeatable side jobs, wallet, shops, upgrades and property income.
- 24-hour cycle in 48 real minutes, five weather states, rain grip penalty.
- Arabic (RTL) and English UI, live 3D main menu, splash with real load progress, HUD, phone, minimap, settings.
- Encrypted local JSON saves; structural save API is unit-tested in CI.

## Build from source

Requirements: Git, Python 3 (asset regeneration only), and a machine with
GitHub Actions access. The CI workflow installs Godot 4.4.1, OpenJDK 17, Android
SDK, imports the project, runs headless smoke tests, exports and signs the APK,
verifies the manifest/signature, and publishes a Release on `v*` tags.

```bash
python3 tools/asset_pipeline/generate_audio.py
python3 tools/asset_pipeline/generate_textures.py
git push origin HEAD:your-branch     # triggers .github/workflows/build-android.yml
```

To build locally: install Godot 4.4.1 plus export templates and Android SDK/JDK,
then `godot --headless --path . --export-release Android build/NovaMira-v0.1.0.apk`.

## Phase 1 foundation (this branch)

Phase 1 adds typed input bindings, versioned save slots, complete offline AR/EN/FR
localization tables, a first-run performance benchmark with four quality tiers,
a 50%–150% resolution-scale slider, a debug/telemetry overlay, and CI gates for
licence audit, APK size (hard fail above 200 MB), smoke tests, foundation unit
tests and real in-game screenshots. The original v0.1 gameplay and native Android
build are unchanged.

CI captures the screenshots directly from the running game with Godot's Movie
Writer mode under Xvfb/llvmpipe; the PNGs in `screenshots/` are committed by the
workflow. On iPhone they can be viewed through the GitHub web page or saved to
Photos; an APK cannot be installed on iOS and no WebView game is used.

Measured Phase 1 export: 26,088,571 bytes (24.88 MiB), no OBB. Budget table:
`docs/SIZE_AND_PERFORMANCE.md`. Verified CI run: `44560909127`.
