# Roadmap

- **v0.1.0 (now):** native APK, 6-district procedural city, on-foot + driving + gunplay,
  5-star wanted system, 5 missions, 4 side activities, wallet/shops, save/load,
  bilingual UI, settings, day/night + weather, 10 vehicles, 8 weapons, 3 radio stations.
- **v0.2.0:** walkable multi-room interiors, proper skeletal ragdoll, per-vertex vehicle
  deformation, roadblock spawn points, dynamic NavMesh baking.
- **v0.3.0:** property interiors with usable furniture, gang territory control,
  more story missions, photos/missions editor, cloud saves.
- **v0.4.0:** Vulkan renderer path with SSR/SSAO on high-end devices, gamepad remapping
  screen, Play Asset Delivery package for Google Play.
- **v1.0:** content expansion to a genuine 4 km² fully detailed city and 20+ missions.
