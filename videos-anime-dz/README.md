# رسوم متحركة قصيرة بالدارجة

خمسة فيديوهات عمودية، كل واحد مدته 40 ثانية. الشخصيات مرسومة ومتحركة بتحريك محدود للذراعين والجسم والفم. حركة الفم تقريبية مرتبطة بشدة الصوت، وليست مزامنة صوتية دقيقة؛ وتوقيت الترجمة تقريبي.

استُخدمت مكتبة التحريك B6 puppet وبيانات الذراع من مشروع [Stickman Video Director](https://github.com/kaomei/stickman-video-director) المرخص MIT، مع مشاهد مرسومة وتعليق صوتي اصطناعي. الصوت ليس مؤكداً أنه مفتوح المصدر، ولا تُضمن دقة اللكنة الجزائرية.
