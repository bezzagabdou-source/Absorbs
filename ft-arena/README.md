# 🏆 مسابقات MX — بوت مسابقات MX + لوحة تحكم متكاملة

منظومة كاملة (بوت تيليجرام + لوحة تحكم ويب) لمسابقات **FT / نقاط / إحالات / جوائز حقيقية**،
مبنية على Next.js 16 وتعمل بالكامل على **Vercel** (Serverless، بدون سيرفر دائم).

---

## ✨ ما يوجد داخل البوت

| الميزة | التفاصيل |
|---|---|
| 🎁 **هدية يومية** | من 1 إلى 3 نقاط (قابلة للتعديل)، + مكافأة سلسلة كل 3 أيام، ومنع التكرار في نفس اليوم |
| 🔗 **نظام إحالات متطور** | `+3` عند دخول الصديق و`+2` عند تفعيله (اشتراكه) — كل القيم قابلة للتعديل من اللوحة |
| 🤝 **إشعار إحالة بالصور** | عند دخول عضو من رابطك يصلك إشعار فيه **صورة الداعي وصورة المنضم** معًا (ألبوم) |
| 👑 **متصدرون لحظيّون** | ترتيب بالنقاط + ترتيب «أفضل الداعين» + ترتيبك أنت داخل البوت |
| 🎡 **عجلة حظ** | جوائز واحتمالات قابلة للتحكم، تبريد بالساعات، ودورات إضافية مع كل عدد إحالات |
| 🛍️ **متجر جوائز** | Netflix 20، Google Play 35، Coinbase 65/75، **بوت + موقع 100** — تُدار كلها من اللوحة |
| 📦 **طلبات الاستبدال** | رمز طلب لكل عملية، مراجعة، موافقة، تسليم، ورفض مع **استرداد تلقائي للنقاط** |
| ✅ **مهام** | اشتراك قناة/زيارة رابط/مهمة يدوية، مرة واحدة أو يوميًا |
| 🏅 **مسابقات** | مسابقات بتاريخ انتهاء وجوائز، وتثبيت الفائزين تلقائيًا |
| 🔒 **اشتراك إجباري** | قناة `@mxabdou` + قنوات إضافية، تحقق حقيقي عبر `getChatMember` |
| 📢 **بث جماعي** | رسالة + صورة + زر، مع استهداف (نشطون/غير نشطين/VIP/لديهم نقاط) وسجل نتائج |
| 🌍 **3 لغات** | عربية / فرنسية / إنجليزية (تلقائيًا حسب لغة تيليجرام) |
| 🛡️ **حماية** | مكافحة السبام، حظر، منع إحالة النفس، منع الحسابات الوهمية، وضع صيانة |

## 🎛️ لوحة التحكم

- **نظرة عامة**: 8 مؤشرات KPI + رسوم بيانية (7/14/30 يوم) + حالة النظام وWebhook + أفضل الأعضاء والداعين + آخر الأحداث.
- **الأعضاء**: بحث/فرز/تصفية، صور الأعضاء الحقيقية، تعديل النقاط، حظر، VIP، رسالة خاصة، سجل حركات.
- **المتجر**: إضافة/تعديل/حذف جوائز، مخزون، صور، وتوليد صور بالذكاء الاصطناعي.
- **الطلبات**: قبول/رفض/تسليم مع إشعار فوري للمستخدم واسترداد النقاط.
- **المسابقات / المهام / العجلة**: إدارة كاملة.
- **البث الجماعي**: معاينة، صورة، زر، جمهور، تجربة، سجل.
- **الإعدادات**: النقاط، النصوص، القناة، الميزات، الصلاحيات، الأمان.
- **🤖 البوت والتشغيل**: حالة الاتصال، **ربط Webhook بضغطة واحدة**، تفعيل الأوامر، رسالة تجربة.
- **🖼️ المكتبة**: رفع صور/ملفات إلى Vercel Blob + توليد صور.
- **🧠 الكونسول الذكي**: اكتب بالعربية «اجعل الهدية من 2 إلى 5 نقاط» أو «أضف جائزة PlayStation بـ 45 نقطة» → **يُطبَّق فورًا على البوت**.
- **📈 السجل**: كل حدث وكل أمر ذكي مع نتائجه.

## 🧠 كيف يعمل الكونسول الذكي؟

1. يقرأ طلبك بالعربية ويحوّله إلى عمليات محددة (`set_points`, `add_reward`, `broadcast`, …).
2. ينفّذها على قاعدة البوت مباشرة — **بدون إعادة نشر**.
3. يسجّل كل عملية في السجل.

- يوجد **محرك فهم عربي مدمج يعمل بدون أي مفتاح** (أرقام عربية ٠-٩، صياغات شائعة).
- إن أضفت أي مفتاح (`GEMINI_API_KEY`, `OPENROUTER_API_KEY`, `GROQ_API_KEY`, `DEEPSEEK_API_KEY`, `XAI_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `CEREBRAS_API_KEY`) يستخدمه تلقائيًا لفهم طلبات أعقد.

## 📱 لوحة التحكم على الهاتف

اللوحة مصممة أصلًا للجوال (Mobile-first) وتعمل بنفس الكفاءة على الحاسوب:

- **شريط تنقل سفلي ثابت** فيه أهم 5 أقسام + زر «المزيد» (يراعي `safe-area` في آيفون).
- **قائمة جانبية منسدلة** مع طبقة تعتيم، تُغلق تلقائيًا عند اختيار أي قسم.
- **صفحة مستقلة لكل زر** — لا تبويبات مخفيّة داخل صفحة واحدة:

| القسم | المسار | القسم | المسار |
|---|---|---|---|
| نظرة عامة | `/admin` | البث الجماعي | `/admin/broadcast` |
| الأعضاء | `/admin/users` | المهام | `/admin/tasks` |
| المتجر | `/admin/store` | الإعدادات | `/admin/settings` |
| الطلبات | `/admin/claims` | البوت والتشغيل | `/admin/bot` |
| المسابقات | `/admin/contests` | المكتبة والصور | `/admin/library` |
| السجل | `/admin/activity` | الكونسول الذكي | `/admin/ai` |

- **الجداول** تُقصّ أفقيًا بسلاسة، **المودال** يصبح ورقة سفلية، **البطاقات** تنزل لعمودين أو عمود.
- حقول الإدخال بمقاس 16px في الجوال لمنع التكبير التلقائي في iOS، وأهداف اللمس ≥ 42px.
- الودجات تأخذ رابطًا نسبيًا `/admin/ai` حتى لا تنكسر في الإنتاج.

## 🧠 الذكاء الاصطناعي — يعمل فورًا

1. افتح `/admin/ai`.
2. اضغط **🔑 مفتاح الذكاء الاصطناعي** → الصق مفتاح **Gemini** (أو أي مزوّد متوافق مع OpenAI).
3. **حفظ وتشغيل فوري** — يُخزَّن في قاعدة البيانات ويعمل مباشرة **بدون إعادة نشر**.

بدون أي مفتاح، يعمل **المحرّك العربي المدمج** ويغطي: الهدية، الإحالات، العجلة، المهام، أسعار الجوائز،
الحظر/VIP، منح النقاط، المسابقات، النصوص، اسم البوت، والميزات.

> ⚡️ عند توفّر عدة مزوّدين يتم **التسابق بينهم بالتوازي** — أول رد صالح يُنفَّذ (مهلة 9 ثوانٍ لكل مزوّد).

## 🚀 النشر

### 1) متغيّرات البيئة (Vercel → Settings → Environment Variables)

| المتغير | إلزامي | الوصف |
|---|---|---|
| `BOT_TOKEN` | ✅ | توكن البوت من @BotFather |
| `ADMIN_PASSWORD` | ✅ | كلمة مرور لوحة التحكم |
| `AUTH_SECRET` | ✅ | سر توقيع الجلسات (32+ حرفًا) |
| `WEBHOOK_SECRET` | ✅ | سر مسار الـ webhook |
| `REDIS_URL` | موصى به | Redis (Redis Cloud / Upstash) — الأسرع |
| `BLOB_READ_WRITE_TOKEN` | موصى به | لرفع الصور والنسخ الاحتياطي |
| `ADMIN_CHAT_ID` | اختياري | معرّف محادثتك لاستقبال إشعارات الأدمن |

بدون Redis يعمل البوت تلقائيًا على Vercel Blob، وبدونهما على الذاكرة (غير مستحسن للإنتاج).

### 2) ربط البوت (مرة واحدة)

افتح `/admin` → **البوت والتشغيل** → **⚡️ ربط تلقائي**. سيقوم بـ:
- ضبط `setWebhook` على `/api/tg/<WEBHOOK_SECRET>`
- تفعيل الأوامر ووصف البوت
- فحص قناة الاشتراك

> مهم: أضف البوت **أدمنًا** في قناة الاشتراك بصلاحية «إدارة الأعضاء» ليعمل التحقق الحقيقي.

## 🧱 البنية

```
src/lib/       # المحرّك: store (Redis+Blob+cache)، bot (كل المنطق)، tg، auth، ai-brain
src/app/api/   # /tg/webhook، /admin/* (18 مسارًا)، /s/[code]
src/app/admin  # لوحة التحكم (Client Console)
scripts/       # اختبارات تشغيل حقيقية
```

- **نقاط مضمونة**: كل تعديل يمرّ عبر `mutate()` بقفل موزّع على Redis → لا تُفقد نقاط مستخدم أبدًا.
- **أمان**: جلسة موقّعة HMAC، مقارنة كلمة المرور بتوقيت ثابت، لا أسرار في الكود، وكل الصور تُخدَم عبر وسيط.
