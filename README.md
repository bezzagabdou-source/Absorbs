## 🚀 النشر على Vercel

1. ارفع المشروع إلى GitHub ثم **Import** في Vercel.
2. في **Settings → Environment Variables** أضف المتغيرات (انظر `.env.example`):

| المتغير | إلزامي؟ | الوصف |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط PostgreSQL (Neon / Supabase / Vercel Postgres) |
| `GEMINI_API_KEY` | ✅ | مفتاح من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| `NEXT_PUBLIC_SITE_URL` | موصى به | نطاقك، مثل `https://barq.example.com` (sitemap وروابط المشاركة) |
| `ADMIN_SECRET` | موصى به | كلمة سرّ (12+ حرفًا) لإنشاء أكواد Pro بدون SQL |
| `CHARGILY_SECRET_KEY` | اختياري | الدفع عبر EDAHABIA / CIB |
| `CHARGILY_MODE` | اختياري | `live` (افتراضي) أو `test` |

3. **Deploy**، ثم **Redeploy** كلما غيّرت المتغيرات.

> ✅ **الجداول تُنشأ تلقائيًا** عند أول طلب — لا حاجة لـ `drizzle-kit push`.
> (اختياري للمطورين: `npm run db:push` يستعمل `DATABASE_URL` من بيئتك.)

## 🎟️ أكواد تفعيل Pro

بدون SQL — اضبط `ADMIN_SECRET` ثم:

```bash
curl -X POST https://YOUR_DOMAIN/api/admin/promo \
  -H "x-admin-secret: YOUR_ADMIN_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"code":"BARQ-VIP","days":30,"maxUses":100}'
```

- كل مستخدم يستعمل الكود الواحد **مرة واحدة** فقط.
- `GET /api/admin/promo` (بنفس الهيدر) يعرض آخر 50 كودًا.

## 💳 الدفع عبر Chargily

1. سجّل في [pay.chargily.com](https://pay.chargily.com) وأضف `CHARGILY_SECRET_KEY`.
2. في لوحة Chargily → Webhooks أضف: `https://YOUR_DOMAIN/api/billing/webhook`
3. الأسعار: **990 دج/شهر** و**9900 دج/سنة** (في `src/app/api/billing/chargily/route.ts`).

## 🤝 فريق الذكاء الاصطناعي الموحّد (Pro)

أضف أي مفاتيح تملكها (`ANTHROPIC_API_KEY` · `GEMINI_API_KEY` · `DEEPSEEK_API_KEY` · `XAI_API_KEY` · `OPENROUTER_API_KEY` · `GROQ_API_KEY`) — كل محرّك له مفتاح ينضم تلقائيًا.

1. **المسوّدات بالتوازي**: كل محرّك يكتب نسخته الكاملة (مع نصاب: بعد وصول مسوّدتين، يُمنح الباقي 15 ثانية فقط).
2. **الدمج**: المحرّك القائد (الافتراضي Claude، غيّره بـ `BARQ_LEAD`) يدمج أقوى ما في كل المسوّدات ويصلح الأخطاء. إن سقط القائد يتولّى التالي تلقائيًا.
3. **ترميم القطع**: إن انقطع الكود بسبب حد التوكنات يُكمَّل ويُغلق (`</html>` + إغلاق الكتلة) تلقائيًا.

يُفعَّل في: «صانع الألعاب» وطلبات البناء (لعبة / موقع / تطبيق) في المحادثة. مواصفات الملف الواحد (HTML واحد، محرّك واحد، حالات MENU→PLAYING→PAUSED→GAME OVER، صوت Web Audio، localStorage، لمس + كيبورد) مدمجة في `src/lib/prompts.ts` (`WEB_SPEC`). التشخيص: `/api/ai/status` يعرض أسماء المحرّكات المتصلة.

## 🛡️ الأمان

- التحقق من توكن Firebase بالتوقيع (RS256) مع فحص `exp` و`aud` و`iss`.

## 👑 جديد: Nexus AI v8.4 Pro الأسطوري

- **مبدّل النموذج** في المحادثة: Nexus 5 · Nexus 6 · **Nexus 8** (الافتراضي لمشتركي Pro). v6 تبقى كما هي بجانبه.
- **فريق ذكاء اصطناعي لكل مهمة صعبة**: `isHardRequest()` في `src/lib/gemini.ts` تكتشف طلبات البرمجة والتعديل والإصلاح والتقارير الطويلة والتحليل العميق (وليس الألعاب فقط)، فتعمل المحرّكات المتصلة بالتوازي ثم تُدمج أقوى إجابة (`ensembleStream` بنمط `kind: "hard"`).
- **لا ينقطع أبدًا**: `keepAlive` + `after()` في `src/app/api/ai/chat/route.ts` — إن خرجت من الموقع/التطبيق يكمل السيرفر ويحفظ الرد، وعند عودتك تظهر النتيجة (استعلام تلقائي في `chat.tsx`).
- **مسارات بديلة**: فشل الفريق ⟵ يتحوّل لأسرع محرّك منفرد؛ فشل الطلب ⟵ إعادة محاولة تلقائية مرتين؛ فشل كل شيء ⟵ استرجاع الرصيد.
- **سرعة**: مسار سريع (`lowThink`) للأسئلة العادية، بث كل 33ms، تحميل الطلبات المتوازية كما في v6.
- **ميزات جديدة في المحادثة**: أوضاع (ذكي/مبرمج/كاتب/معلّم/محلل) · أزرار اقتراحات بعد كل رد (`<<next: …>>` تُخفى تلقائيًا) · زر «استماع» لكل رد · **محادثة صوتية مباشرة** (تكلّم ⟵ يرد بصوته ⟵ يستمع من جديد).
- **شاشة التفعيل المتحركة** (`src/components/pro-activation.tsx`): تظهر بعد إدخال كود أو نجاح الدفع، وأول مرة يفتح فيها حساب Pro التطبيق، ومن زر «استعرض ميزات Nexus AI v8.4 Pro» في صفحة الترقية. كل ميزة فيها زر «جرّبها» يفتح المحادثة ويرسل مثالًا جاهزًا (`/app?q=…`).
- أكواد التفعيل القديمة (`PRO-CODES-V8.txt`) تعمل كما هي.

- 🏗️ **`src/lib/titan.ts`** — بناء حتى **5 م.ب**: `stitch()` يحذف التداخل بين المقاطع (نهاية عطل الكود المكرّر)، `integrity()` يعدّ الأقواس خارج النصوص والتعليقات، `repair()` يغلق ما تُرك مفتوحًا، و`glitchScan()` يكشف العناصر النائبة والصور الخارجية و canvas بلا حلقة رسم.
- 🧩 **`src/lib/fusion.ts`** — تنقيط كل مسودّة (اكتمال · حجم · أعطال · لغة) ثم دمج بقاعدة **«عمود فقري + متبرّعون»** حتى لا يختلط تصميمان.
- 🎨 **`src/lib/design-canvas.ts`** — 8 أنواع artifact حيّ (ملصق · شعار · واجهة · لوحة تحكم · رسم بياني · مستند · عرض · مخطط) تُرسم بجانب المحادثة بلا أي طلب شبكة.
- 🔤 **`src/lib/arabic-vision.ts`** — قاموس دارجة→إنجليزية للصور، حماية النص العربي الحرفي داخل الصورة، و`ARABIC_VISION_SYSTEM` لقراءة الفواتير والأوراق المدرسية سطرًا بسطر.
- 👑 **`src/lib/nexus-v11.ts`** — ستة قوانين (سرعة · عقل · بناء · تصميم · عربية · صدق) تُحقن في طبقة MAX.
