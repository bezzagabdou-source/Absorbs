# «نقطة» — NEXUS · أول فيديو للقناة

فيديو عمودي 1080×1920 · 30fps · 39.6 ثانية (35.5 ثانية فيلم + 4 ثواني بطاقة نهاية) · صوت بشري عربي + موسيقى أوركسترالية أصلية.

**الملف النهائي:** [`out/nexus_point_1080x1920.mp4`](./out/nexus_point_1080x1920.mp4)

## الفكرة
مستوحى من صورة «النقطة الزرقاء الباهتة» التي التقطتها ناسا سنة ١٩٩٠. السرد يفتح على أصغر شيء، ثم يفتح الكادر
إلى الشمس والمجرّة وتريليونات المجرّات، ثم يعود كل شيء إلى نقطة واحدة:

> كل شيء عظيم... يبدأ من نقطة.

## الإنتاج
كل شيء مولَّد برمجياً (`build/`):

- `engine.py` — كاميرا، جزيئات، توهج/bloom، حبيبات فيلم، ومحرّك نص عربي على **HarfBuzz + FreeType**
  (تشكيل ووصل الحروف وbidi صحيح 100%، خطوط Almarai / Tajawal / Anton).
- `shots.py` — اللقطات العشر، التدرّج اللوني (تيل في الظلال، دافئ في الإضاءة)، الاهتزاز، الفلاشات.
- `audio.py` — بارتيتورا أصلية: بادات أوركسترالية، باص، أربيجيو، نبض قلب، رايزرات، ومؤثرات — كلها تخليق رقمي،
  بلا أي عيّنة محمية بحقوق، مع ducking تلقائي تحت الصوت البشري.
- `render_all.py` — يبثّ الإطارات إلى ffmpeg (H.264 High, yuv420p, BT.709) ويصبغ الصوت `loudnorm=I=-14`
  (معيار تيك توك).

## إعادة التوليد
```bash
python -m venv .venv && .venv/bin/pip install pillow numpy uharfbuzz freetype-py soundfile imageio-ffmpeg
python build/audio.py        # -> out/mix.wav
python build/render_all.py   # -> out/nexus_point_1080x1920.mp4
```
يتطلّب الخطوط في `/home/user/fonts` (Almarai, Tajawal, Anton, Space Grotesk — رخصة OFL) و`assets/*.png`
(٤ صور فضاء مولَّدة). الصوت البشري: `vo/01..05.mp3` مقسَّم على الجُمل ثم يُعاد تركيبه بدقة على `build/segments.json`.
